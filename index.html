🧠 Genal Activation Family

Redefiniendo el Deep Learning con funciones de activación dinámicas y entrenables.

¿Qué es esta tecnología?

La Genal Activation Family es una suite de funciones de activación creadas por Genal Ediso Lombano Pineda. A diferencia de las funciones estáticas tradicionales (como ReLU o GELU), esta familia introduce parámetros dinámicos (k y beta) que se entrenan mediante retropropagación (backpropagation).

Esto permite que la red neuronal adapte su curva de activación en tiempo real según los datos que está procesando, evitando el colapso del gradiente y encontrando mínimos más profundos.

La Familia de Funciones

1. GenalShift

Introduce un desplazamiento horizontal entrenable (beta) junto con el parámetro de curvatura (k). Es la función estrella del benchmark.

2. GenalAdvanced

Optimiza un parámetro k independiente para cada canal (feature map). Ideal para capas convolucionales (CNN) donde cada filtro busca un patrón distinto.

3. GenalActivation

Utiliza un escalar global para suavizar la curva. Ideal para capas densas (Fully Connected) en procesamiento de lenguaje o tablas.

4. GenalLeaky

Garantiza un flujo de gradiente mínimo (alpha) para valores negativos, evitando que las neuronas "mueran" durante entrenamientos largos.

💻 Uso Rápido en PyTorch

import torch.nn as nn
from genal_activation import GenalShift

# Uso en una red convolucional
self.conv1 = nn.Conv2d(3, 16, 3)
self.act1 = GenalShift()

# La red ajustará k y beta automáticamente
