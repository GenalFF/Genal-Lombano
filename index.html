🧠 Genal Activation Family

Redefiniendo el Deep Learning con funciones de activación dinámicas.

¿Qué es esta tecnología?

La Genal Activation Family es una suite de funciones de activación entrenables creadas por Genal Ediso Lombano Pineda. A diferencia de ReLU o GELU que son estáticas, nuestras funciones ajustan sus parámetros (k y beta) en tiempo real durante el entrenamiento, evitando el colapso del gradiente.

Instalar vía PyPI

💻 Uso Rápido (PyTorch)

import torch.nn as nn
from genal_activation import GenalShift

# Usar en una red neuronal
self.capa = nn.Linear(64, 128)
self.activacion = GenalShift()
# ¡Listo! El modelo aprenderá el mejor parámetro k y beta.
