## 🚀 Proyectos Desarrollados (SaaS y IA Aplicada)

### 1. 🛡️ Genal Fraud Detect (Detección de Fraude Bancario)
Sistema de Machine Learning diseñado para identificar transacciones sospechosas en tiempo real. Utiliza PyTorch y la arquitectura Genal Activation para lograr un **97.5% de precisión** y un **94.6% de AUC**.
- **Tech Stack:** Python, PyTorch, Streamlit, Scikit-Learn, Plotly.

### 2. 🏪 Sofi Pro (Sistema de Inventario Inteligente)
Plataforma SaaS para supermercados y farmacias que predice compras, detecta productos por vencer y calcula márgenes de ganancia. Implementa autenticación segura (Hash) y modelos de predicción de ventas.
- **Tech Stack:** Python, Streamlit, Pandas, Plotly, JSON Auth.

### 3. 💊 Farma-RAG (Asistente Médico Extractivo)
Sistema RAG (Retrieval-Augmented Generation) de alta seguridad. Lee vademécums médicos (PDFs) y responde preguntas de farmacología. Gracias a su sistema de "abstención", es incapaz de alucinar: si la respuesta no está en el texto, el sistema dice "No lo sé".
- **Tech Stack:** Python, LangChain, FAISS, HuggingFace, PyMuPDF.
